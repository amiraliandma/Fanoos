# فانوس (Fanoos)

اپلیکیشن اندروید سبک، مینیمال، روشن و سالمندپسند بر پایه هسته **Xray-core** پروژه [PattNG](https://github.com/patterniha/PattNG) (مخصوص پردازنده‌های `arm64-v8a`).

## ویژگی‌ها
- طراحی تک‌صفحه‌ای، روشن و کاملاً ساده بدون تنظیمات پیچیده
- دکمه بزرگ اتصال/قطع اتصال در بالای صفحه
- بروزرسانی لیست سرورها و تست پینگ واقعی با مرتب‌سازی خودکار سریع‌ترین سرورها
- پشتیبانی کامل از پروتکل‌های **VLESS** (شامل بدون رمزنگاری)، **VMess**، **Shadowsocks 2022**، **Hysteria2** و **Trojan**
- تنظیمات پیش‌فرض بهینه بر پایه PattNG با **DNS گوگل (`8.8.8.8`)** و **قوانین روتینگ ایران** (عبور مستقیم سایت‌ها و IPهای ایران)
- ساخت خودکار فایل APK (فقط `arm64-v8a`) از طریق **GitHub Actions**
